Conceitos de Endereçamento IPv4

Conceitos de endereço de rede, máscara, gateway, broadcast e prefixo utilizados no planejamento.

DOCUMENTO 005

Conceitos de Endereçamento IPv4

Rede utilizada no planejamento

Endereço da rede: 192.168.50.0

Máscara: 255.255.255.0

Prefixo: /24

Gateway planejado: 192.168.50.1

Broadcast: 192.168.50.255

Conceitos importantes

Endereço de rede: identifica a rede IPv4.

Gateway: dispositivo pelo qual os computadores encaminham tráfego destinado a outras redes, normalmente o roteador.

Broadcast: permite enviar tráfego para todos os dispositivos da sub-rede IPv4.

Máscara de sub-rede: ajuda a determinar qual parte do endereço IP identifica a rede e qual parte identifica o dispositivo.

Planejamento conceitual: nenhuma configuração foi aplicada à rede doméstica.

Procedimento de Diagnóstico de Internet

Etapa 1 — Verificar configuração IP
ipconfig /all

Verificar endereço IPv4, máscara, gateway, DHCP e servidores DNS.

Etapa 2 — Testar o gateway
ping 10.0.0.1 -n 4

Verificar se o computador consegue comunicar-se com o gateway.

Etapa 3 — Testar conectividade externa
ping 8.8.8.8 -n 4

Verificar a comunicação com um endereço IP externo.

Etapa 4 — Verificar DNS
nslookup google.com

Verificar se o nome do domínio está sendo resolvido para um endereço IP.

Registro do atendimento
  • Problema relatado.
  • Equipamento e conexão afetados.
  • Comandos executados.
  • Resultados observados.

DOCUMENTO 008

Procedimento de Diagnóstico DNS

Objetivo

Verificar se um nome de domínio pode ser convertido em endereço IP por meio de uma consulta DNS.

Comando utilizado
nslookup google.com
O que observar
  • Servidor DNS consultado.
  • Nome do domínio pesquisado.
  • Endereço IP retornado.
  • Mensagens de erro, se existirem.
  • Data e horário do teste.
Interpretação

Quando a consulta retorna um endereço IP, significa que houve resolução do nome consultado.

Uma consulta DNS bem-sucedida não garante, isoladamente, que todos os sites e serviços estejam acessíveis.
